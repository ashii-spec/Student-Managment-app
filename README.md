# Student-Managment-app
🎓 Student Management System (Backend)

A simple Student Management REST API built using Node.js and Express.js.
This backend application allows you to create, read, update, and delete (CRUD) student records such as name, age, and course.

🚀 Features

Add new students

View all students

View a single student by ID

Update student details (name, age, course)

Delete student records

Uses an in-memory database (easy to upgrade to MongoDB later)

🛠️ Technologies Used

Node.js

Express.js

Body-parser

REST API principles
